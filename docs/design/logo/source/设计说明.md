## 二、维护者 11-10 选定的方向

1. 云织：**保留骨架重画**（枝杈 + 双干 + 底座），重定网格、比例和线宽。
2. 流息：讲**多条信息流汇成一条**。

## 三、设计语言

**方法：模数网格造型。** 整个标只用一个单位格：线宽 = 1 格，线与线的间隔 = 1 格，只允许水平、垂直、45° 三种方向，所有外露的线头统一做 45° 斜切。两个标共用这一套规则，所以放在一起一眼是一家；图形本身一个竖、一个横，所以不会认混。

**参照的流派与作品（取方法，不取符号）：**

- 国际主义平面设计（瑞士风格）的「程序化设计」：Karl Gerstner《Designing Programmes》（1964）——先定规则，再让图形从规则里长出来。
- Otl Aicher 1972 慕尼黑奥运会图标系统：全部图形落在同一张正交 + 45° 网格上，所以几十个图标是一家。
- Wim Crouwel《New Alphabet》（1967）：只用横、竖和 45° 切角造字，线宽与间隔同一模数。

流息 v2 的默认主题就叫「精密国际主义」，标和界面是同一种语言。

**明确不取的：**

- 云朵轮廓、水滴、曲线波浪——通用图形，认不出是谁。
- 把回纹、祥云当装饰用。云织底座里那一道折是「通道」，是结构，不是花纹。
- 渐变、发光、AI 星星火花。
- 首字母 Y / S。
- 任何像 Claude、OpenAI 的图形（流息的合规要求：产品名和 logo 里不出现接入方的品牌）。

## 四、每个元素对应什么

**云织（竖向：往上长、立得住）**

| 元素 | 对应 |
|---|---|
| 竖线 | 经线，也是一条条资料线索 |
| 45° 并线 | 线索一步步并进主干：收集资料 → 拟定提纲 |
| 双干与中间的缝 | 织机上的经线对；缝是通道，一直通到底座里 |
| 阶梯底座 | 交付物立在底稿和证据上；上宽下窄沿用原标的轮廓 |
| 通道在底座里的一折 | 原标回纹的简化：线索进了底座还能回溯——溯源 |
| 线头斜切、左干高右干低 | 原标的笔意，保留 |

**流息（横向：流过去、汇起来）**

| 元素 | 对应 |
|---|---|
| 左侧几条平行线 | 几个来源 |
| 线头错开 | 各来源更新时间不一，不是一起到的 |
| 45° 并线 | 筛选流水线：一关一关并下来 |
| 右侧一条线 | 留下来的那一条，进你的库 |
| 线头斜切方向一致（/） | 向右流的方向感 |

**家族关系一句话：** 云织是这套线竖起来、落在底座上；流息是同一套线横过来、汇成一条。

**定稿的两个标**

- **云织 · 扣**：两根线，一根从右往左弯、一根从左往右弯，互相扣住（第四轮选的是竖版，第五轮 维护者 让顺时针转 90°，再左右镜像，定稿是镜像后的横版）。讲的是「织」：把线索扣成一件东西。9 × 7 格，四条横线等宽等距。原第三节「保留骨架」和第四节云织的元素表不再适用（维护者 已放弃枝杈、底座、塔和树）。
- **流息 · 五流**：五条线分两级汇成一条。13 × 9 格。第四节流息的元素表仍然适用。
- **家族规则不变**：线宽 1 格、间隔 1 格、只有 0° / 90° / 45°、外露线头 45° 斜切。
- **配色**：白底黑标，红 `#E53935` 向左、蓝 `#1E88E5` 向右各错开一点，黑标压在上面。两个标都错半格（0.5 格）：定稿都是横线为主，左右错位落在线头和斜边上，不会填掉线之间的缝。小尺寸一律错 1 像素，16px 只用黑白。
- **字标**：中文为主（微软雅黑粗体）+ 英文小字（CIS / STREAMS；云织旧 lockup 写的 YUNZHI 不再用），中文用墨色 `#111827`、英文用灰 `#4B5563`（沿用云织旧 lockup）；字是活字不是轮廓，换机器没有这几款字体会回退。
