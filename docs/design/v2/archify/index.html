流息 v2 架构图 · 总览

开工前给 维护者 过目的计划图（依据 docs/design/v2/architecture.md），图上的模块都还没有建。

  1. 1. 架构大图

    页面 → 桥 → 主进程 → 核心（照搬 / 新写分色）→ 模型角色与三种连接，加上应用数据和每个库文件夹两处存储，以及「不能动手」、只经 writeNoteFile、只认「确认」等权限边界。

  2. 2. 一轮怎么跑（数据流）

    从定时到点 / 现在跑一轮 / 确认了开跑提议，到排队、抓取、去重、两道关、摘要、核验（含「写给 AI 的话」规则）、待看、规则型建议和左栏数字，标出哪步是代码、哪步是库 Agent 调用。

  3. 3. 提议卡怎么走（时序）

    你在库内对话框说一句改动 → 分流转给主 Agent → 主 Agent 回 JSON 并经代码查 lookups（最多 3 次）→ 代码校验、试抓、出卡 → 你确认 → 代码改配置并记 proposals.jsonl 与「主 Agent 提的 · 你确认的」。

每张图旁边的 *.candidate.json 是 archify 的输入；图由 archify 生成并通过它自己的校验。
