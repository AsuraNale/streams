# 云织 · 第十一轮开发交接

完整解压后双击 index.html，可离线打开三版。templates 下三个名称以「-第十一轮」结尾的目录分别是澄明玻璃、精密国际主义、研究对话。三版用户评分均为 85/100。

## 找代码

- 从所选模板的 index.html 开始，按 link 和 script 顺序查看。保留相对路径和样式加载顺序。
- shared/round8/app.js 渲染三栏、进度与阅读视图，也包含示例项目及模拟操作。positionPhaseDots() 将进度点放在阶段状态旁。
- shared/round9/edition.js 与主题 CSS 提供图标和主题基础。shared/round11/edition.js 组织本轮主题，workbench.css 和 interactions.js 提供本轮样式和交互。早期轮次目录与「精密国际主义-精修」目录中随包保留的文件均为模板依赖。
- shared/fonts 包含本地中文字体及对应的 OFL 许可。

## 接入正式产品

用原型对照现有组件，按各主题迁移字体、图标、按钮、选中反馈和动效。正式项目继续使用自己的数据模型、文件服务、确认流程和 AI 会话接口。示例项目、localStorage、模拟回复计时器和顶部试用控件属于演示层。
验收时在相同项目、相同阶段比较三栏，逐项核对按钮悬停和按下、项目选中、分栏拖动、选区批注。右栏的三个进度点跟随阶段状态文字，收起阶段后也应可见。
