## 维护者 过目的（2026-11-11，三项都选「照这样」）

1. **验收标准改字**（R6 写进 `standards.mjs`，测试跟着改）：
   - V6：登录过期时，本次运行不开始，库页顶上的横幅说明，已抓取的条目完整保留
   - V8：一个故意写坏的 .md 被列为「缺少文件头」的文件，不进索引、图谱、问库，且文件内容未被改动
   - V9：问库答案的每个引用编号都在候选集内；库里没有的问题得到「库内暂无相关内容。」
   - V10：单次运行上限生效：上限设 5，第 6 条不调模型，剩余条目下次运行接着处理
   - V3 原文不变；测试里五种状态的文案换成 正常 / 无更新 / 地址无效 / 暂时失败 / 访问被拒。
2. **规则提议的动作表**（R5 照此施工；点一下由流息的代码执行、不调模型，每张都要点）：
   - ① 来源连续 3 次暂时失败或访问被拒 → 暂停该来源 · 修改地址… · 交由主 Agent 分析 · 忽略
   - ② 连续 3 次运行没有新条目进待看 → 严格程度放宽一档（已是宽松则不显示）· 交由主 Agent 分析 · 忽略
   - ③ 某来源的文章里有面向 AI 的指令 → 暂停该来源 · 交由主 Agent 分析 · 忽略
   - ④ 和另一个库主题重合 ≥ 60% → 交由主 Agent 分析 · 忽略
   - ⑤ 同一放弃理由最近出现 3 次 → 生成修改提议（主 Agent 写追踪要求的修改前 / 修改后）· 忽略
3. **Noto Serif SC 同意下载**：从 GitHub notofonts/noto-cjk 官方发布取 `NotoSerifSC-VF.ttf`（约 25 MB，OFL 1.1），不用 `C:\Windows\Fonts` 里系统带的那份（R6）。
