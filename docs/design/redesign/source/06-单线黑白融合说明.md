## 一、结论：这套美术只换皮，不动结构

**单线黑白是一套主题（颜色取值 + 形状规则 + 图标），不改信息架构、不改栏位、不改流程。所以布局包不用停，可以先做。**

依据（我看了什么）：

- `UI设计\流息-单线黑白-展示.html` 和它的源稿 `UI设计\流息\`：这是我 11-10 在玄翎 K1 设计稿上加的第四套主题。和另外三套相比只多了 `css/line.css`（形状规则）、`tools/tokens-data.mjs` 里的 `line` 一组取值、一套图标和左上角的新标；`css/app.css`、`css/themes.css`、`js/data.js` 和流息仓里的逐字节相同。三栏、标签、页面结构都没有动。
- 丽芙的云织第十一轮开发包（`独立Agent-丽芙云织-设计看板` 下的那个 zip）：按文件清单看，就是 K1 设计稿的来源（第十一轮开发包：`shared/round3–11` 的样式与脚本、三个模板、字体），流息仓里 `docs/design/next/themes-source/` 已有一份原样副本。这次不需要从里面再取东西。我没有把它和仓里那份逐字节比对。
- 单线黑白的规则一共四条：只有黑白灰（红蓝只在左上角的标上）；选中 = 黑白反转；状态不靠颜色、靠形状；线头和切角只有 0 / 90 / 45 度。四条都是「怎么画」，没有一条是「放在哪」。

**但它不是只换几个颜色值。** 另外三套主题用琥珀 / 绿 / 红表达状态，这一套把它们全换成了形状。新布局里凡是靠颜色说话的地方，都要有一个对应的形状，否则「需要确认」「正常」「有问题」会长得一样。这就是下面冲突清单的主体。

## 二、给玄翎的施工顺序

1. **现在：布局包先做**，外观沿用现有三套主题。路由与页面结构、字典换词（05）、三处后台新能力、验收标准的改动，都和美术无关。
2. **布局包里顺手做一件事**：新部件写样式时只用 `--st-*` 变量，状态用语义类名（需要确认 / 完成 / 未开始 / 运行中 / 有问题），不要直接写琥珀、绿这些颜色。这样第四套主题进来时只加规则、不改结构。
3. **布局包验收后：美术包**（第四套主题「单线黑白」）。照 `UI设计\落地说明-流息-单线黑白.md` 的落点做，再加上本文第四、五节里新布局带来的规则和部件。
4. **可以并行的**：`tokens-data.mjs` 加 `line` 一组、`themes.mjs` 认得第四套、设置页多一张主题卡、应用图标换新标——这些不碰页面，布局包进行中就能做。
5. **不建议合成一个包**：两包一起做，验收时分不清一处不对是布局错了还是主题错了；截图基线也只能等两样都稳了才能定。

## 三、状态 → 形状对照表

单线黑白里没有颜色可用，下面这张表是唯一的状态语言。代表性页面和新增部件页都是照它画的。

| 状态 | 另外三套主题怎么表达 | 单线黑白怎么画 | 稿上的例子 |
|---|---|---|---|
| 需要确认或注意 | 琥珀底、琥珀字 | 左边一条 45° 斜纹 + 墨线框 | 连接出问题的横幅、放弃后的原因条、「检测到面向 AI 的指令，已忽略」、漏斗里「进入待看」一格 |
| 正常或完成 | 绿色签 | 实心黑、切一个角，白字 | 「正常 · 5 条」「核验通过」「已收藏」、漏斗里做完的格 |
| 未开始或排队 | 灰色 | 空框（墨线、白底）；不能点的是虚线框 | 「无更新」「待评分」、漏斗里没到的格、「排队中 · 第 2 位」按钮 |
| 运行中 | 琥珀底按钮 | 按钮左边斜纹 + 墨线框；漏斗当前格斜纹；量条实心、右端斜切 | 页头「运行中 · 停止」、P07 的漏斗 |

| 当前选中 | 浅色底 + 定位条 | 黑白反转 + 切角；列表里的当前卡片是浅灰底 + 左边一条黑 | 左栏当前库、当前标签、右栏当前标签、待看的当前卡片 |
| 数量 | 琥珀数字 | 实心黑切角的小角标，白字；所在的标签被选中时反白 | 「待看 2」「待确认 4」、左栏库名后的数字 |
| 主动作与次动作 | 深色实心 / 浅灰 | 主动作实心黑切角；次动作墨线框；可撤回的弱动作虚线框 | 「确认 / 提出修改 / 拒绝」「撤销」 |

## 四、冲突清单

每条三样：新布局的哪里、撞上单线黑白的哪条规则、怎么解决。前 7 条是「靠颜色表达状态」的六类用色点，后面是其它。

| # | 新布局的哪里 | 撞上哪条规则 | 怎么解决 |
|---|---|---|---|
| 1 | **提示横幅**：连接出问题的横幅、放弃后的原因条、「追踪要求已更新，重新评分」的提示、加来源时的试抓结果、设置里的新版本提示（默认主题下都是琥珀底） | 界面里没有彩色；「等你的东西」= 斜纹 + 墨线框 | 五处统一成左边一条斜纹 + 墨线框。横幅里的主动作实心黑，次动作墨线框 |

| 3 | **状态签（要人看的一类）**：「暂时失败」「地址无效」「访问被拒」「检测到面向 AI 的指令，已忽略」「缺少文件头」「未登录」「来源异常」（默认是琥珀底） | 没有琥珀；有问题的来源 = 加粗 + 波浪下划线 | 斜纹签（左边斜纹 + 墨线框）；在来源表里，这一行的来源名同时加波浪下划线 |

下面是题目原文，留作记录。

前四条 11-10 做单线黑白时已经列过（见 `UI设计\落地说明-流息-单线黑白.md` 第三节），当时没定；现在布局也在改，一并再列。A 是我推荐的。

1. **单线黑白是加成第四套主题，还是替换现有三套里的一套？**
   - **A（推荐）第四套。** 11-10 你选的就是这个；另外三套不动。
     代价：「三套主题」是你 11-10 定的硬约束，要改口成四套；设置页多一张主题卡；截图基线从六组变八组。
   - B 替换掉一套（比如研究对话）。
     代价：已有用户选了那一套的要迁移；那一套的设计白做。
2. **默认主题换不换？**
   - **A（推荐）不换**，精密国际主义仍是默认。
     代价：新装的用户第一眼看不到单线黑白，要去设置里选。
   - B 换成单线黑白。
     代价：要动默认值和旧设置的迁移表；所有以默认主题为准的截图和验收基线重做。
3. **英文界面里这一套叫什么？**
   - **A（推荐）Monoline。** 和 Precision / Clear Glass / Research 是一类词。
     代价：无。
   - B Line。
     代价：太泛，和「线」的其它用法容易混。
4. **应用图标（任务栏、安装包）要不要一起换成新标？**
   - **A（推荐）一起换。**
     代价：要重出各尺寸的 `.ico`；小尺寸是按整像素出的，没有逐像素手调。
   - B 先不换。
     代价：左上角是新标、任务栏是旧的三条波浪，对不上。
5. **美术包排在布局包后面，还是合成一个包？**
   - **A（推荐）排在后面**，布局包验收后再做。
     代价：页面的截图基线要定两次（布局一次、新主题一次）。
   - B 合成一个包。
     代价：验收时分不清是布局错还是主题错；工作包大，出问题难回退。
6. **图标按不按主题换？**
   - **A（推荐）先不换**，只用线头、拐角、线宽三个变量（平头、尖角、线宽 2）。
     代价：现有图标里带曲线的（时钟、搜索、设置）和「只有 0 / 90 / 45 度」不完全相符。
   - B 单线黑白用自己那 33 个图标。
     代价：图标组件要按主题取图标，名字要和应用里的对一遍。
