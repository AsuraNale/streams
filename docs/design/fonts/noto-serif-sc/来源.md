# Noto Serif SC（研究对话主题的标题字体）的来源

- **是什么**：Noto Serif SC 可变字体（TrueType，字重 200–900），SIL Open Font License 1.1。研究对话主题的标题用它（模板 `round9/research.css` 的 `--display-chinese: 'Noto Serif SC', 'SimSun'`）。
- **谁定的**：维护者 2026-11-11（`docs/design/redesign/施工计划.md`「维护者 过目的」第 3 条）：从 GitHub `notofonts/noto-cjk` 官方发布取，不用 `C:\Windows\Fonts` 里系统带的那份，不用第三方镜像。
- **发布**：`notofonts/noto-cjk` 的 release **`Serif2.003`**（Noto Serif CJK Version 2.003，2024-07-30 发布）——<https://github.com/notofonts/noto-cjk/releases/tag/Serif2.003>
- **下载地址**：<https://github.com/notofonts/noto-cjk/releases/download/Serif2.003/03_NotoSerifCJK-TTF-VF.zip>（发布附件，整个 245,858,727 字节）。`NotoSerifSC-VF.ttf` 不是单独的附件，它在这个 zip 里：
  - `Variable/TTF/Subset/NotoSerifSC-VF.ttf` → `desktop/src/renderer/fonts/NotoSerifSC-VF.ttf`
  - `LICENSE`（发布里随附的 OFL 原文）→ `desktop/src/renderer/fonts/OFL-NotoSerifSC.txt`
- **怎么取的**：没有下载整个 246 MB 的 zip（维护者 同意的是约 25 MB）。用 HTTP 分段请求读 zip 末尾的目录，再只取这两个条目的压缩数据（共约 15.5 MB），用 Node 的 `zlib.inflateRawSync` 解开，逐个核对 zip 目录里记的长度与 CRC-32。取到一个新建的空文件夹里，只当数据处理（没有运行里面的任何东西），核过文件头是 TrueType（`00 01 00 00`）、算过 sha256，再复制进仓库。仓库的 `.gitattributes` 是 `* -text`，提交与检出都不改换行。
- **取的时间**：2026-11-13T17:39:37Z（东部时间 11-13 12:39）。
- **没有改动**：两个文件与发布里的条目逐字节相同（未子集化、未改名表、未转格式）；`OFL-NotoSerifSC.txt` 只是把 `LICENSE` 换了文件名。

## 清单与复核

- `source-sha256.txt`：每行 `<sha256>  <仓库里的路径>`，两行。
- `source.json`：发布的 tag、页面、附件地址与大小、取的时间，每个文件在 zip 里的条目名、字节数、压缩后字节数、CRC-32、sha256，字体的文件头、family、version、字重范围。
- `node docs/design/fonts/noto-serif-sc/check-source.mjs`：仓库里的两个文件对清单与记录（字节数、sha256、CRC-32、文件头、名表里的 family 与 version）。只读。
- `node docs/design/fonts/noto-serif-sc/check-source.mjs --release`：再把记录对回官方发布本身——重新用分段请求从发布的 zip 里读出这两个条目（约 15.5 MB，只进内存、不写盘、不运行），与记录逐项比。要联网。
- 桌面测试 `desktop/test/r6a.test.mjs` 每次都跑前一条（不联网）。

## 用到哪里

- `desktop/src/renderer/styles/base.css` 的 `@font-face { font-family: 'Noto Serif SC'; src: url('../fonts/NotoSerifSC-VF.ttf') … }`，经 `app://ui/fonts/NotoSerifSC-VF.ttf` 加载（`desktop/src/main/protocol.mjs` 发 `font/ttf`）。见 `docs/desktop.md` 的字体一节。
- 设置 → 许可证与致谢（`desktop/src/main/licenses.mjs` 的 `DISPLAY_FONT`）；安装包的 `THIRD-PARTY-NOTICES.txt` 第 6 节（`installer/fonts.mjs`、`installer/notices.mjs`）。
